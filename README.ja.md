## これは何か

- **本物の町。** 地形、海岸線、道路、そして 50,826 棟すべての建物の形は、国土地理院のオープンデータから作っています。屋根の色は国土地理院の航空写真から拾っています。架空の街区生成器で並べた建物はありません。
- **手描きのルック。** セル調のエンジンは Kenton-GMI さんの [Sakuragaoka Station](https://github.com/Kenton-GMI/sakuragaoka-station)（MIT ライセンス）を移植したものです。色に合わせた輪郭線、青紫の影、描いた雲、ブルームと色調補正で描きます。
- **内湾はすみずみまで。** 内湾からおよそ 380 m の範囲は、どこでも歩けます。八日町、魚町、南町、神明崎、第7岸壁、防潮堤の遊歩道です。お店には看板や暖簾があり、ガラス越しに中の部屋が見えます。自販機、電線のたるんだ電柱、猫、町の人たちもいます。店名はすべて架空です。
- **港。** まぐろはえ縄船とさんま船が列になって係留され、魚市場の岸壁、内湾の岸壁、南町の岸壁にも漁船が並びます。今日入港した船は、その日のうちは魚市場に着いたままです。魚市場ではかつお一本釣り船が水揚げをしています。浮見堂、五十鈴神社の鳥居と社殿、安波山の展望台、かなえ大橋（気仙沼湾横断橋）、気仙沼大島大橋、大島へのフェリーも見えます。
- **移り変わる町。** 時刻は 朝 06:30・昼 12:00・夕方 16:30・夕焼け 17:20・夜 19:30 の五つで、どれも 2026年10月10日 の光で描いています。季節は 春・夏・秋・冬 の四つです。雨と濡れた路面、港の環境音もあります。
- **ライブデータ。** 天気は気象庁のアメダスと天気予報、今日の入船は気仙沼漁協の入船情報から取っています。リストにある船は、実際の船名で魚市場へ入ってきます。ライブの取得に失敗したときは保存済みのサンプルを表示し、**サンプル** と明記します。サーバーがキャッシュからしか答えられず、それが 1 時間より古いとき（または入船リストが前日以前のもののとき）は、ライブではなく **キャッシュ** とその時刻を表示します。
- **ツアーと写真。** 名所は 7 か所で、名所の間はドローンで飛び、自動ツアーもあります。どの名所にも地上の歩き出し地点があります（「歩く」または V）。湾全体を見渡す「小さな惑星」表示と、3840×2160 の PNG を保存する写真モードもあります。UI は日本語と英語に対応し、スマートフォン用の画面もあります。

## 動かし方

[Bun](https://bun.sh) 1.3 以降と、WebGL2 に対応したデスクトップブラウザが必要です。Apple シリコンの Mac で Chrome か Safari を使うのがおすすめです。

```sh
bun install
bun run build                                  # src/anime を dist/ にまとめる（1 秒未満）
bun run scripts/serve.js --port 8787 --no-build
# http://127.0.0.1:8787/ を開く
```

- `bun run serve` なら、ビルドしてからポート 8787 で配信するまでを一度に行います。
- サーバーは 127.0.0.1 だけで待ち受けます。`/` で `dist/`、`/data/` で `data/` を配信し、`GET /api/live` で今日の天気・潮位・入船を返します。
- 初回の読み込みでは、ブラウザの中で町全体を組み立てます。共有中で速度を絞った M2 Max では 15〜20 秒ほどかかりました。進み具合は駅名標に表示されます。
- シェルで `NODE_OPTIONS` を設定している場合（デバッガ用など）は、各コマンドの前に `env -u NODE_OPTIONS` を付けてください。

そのほかのコマンド:

```sh
bun test                                       # 259 件のテスト（レイアウト、モジュール、ライブ解析、i18n、決定性、歩き出し地点）
bun run scripts/live.js                        # 今日のライブ状態を表示（気象庁 + 気仙沼漁協）
bun run scripts/live.js --fixtures             # 保存済みサンプルの状態
bun tools/anime/check.mjs town                 # ワールドモジュール一つ分のポリゴン数とテクスチャ量の確認（GPU 不要）
```

スクリーンショット、QA、静止画、動画のツールは、実 GPU を使うヘッドレス Chrome で動きます。詳しくは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#tools) を見てください。

## 操作

駅名標の **まちへ出る · Enter the town** をクリックするか、Enter キーを押します。

| キー | 操作 |
|---|---|
| W A S D / 矢印キー | 歩く（岸壁の縁は壁になっていて、海には落ちません。飛行中は飛ぶ） |
| マウス | 見回す。画面をクリックするとポインタを固定し、Esc で解除します。固定しないときはドラッグで見回します。 |
| Shift | 走る |
| Space | ジャンプ（飛行中は上昇） |
| E / Q | 上昇 / 下降（飛行中） |
| F | 飛行のオン・オフ（飛行中は壁を通り抜けます） |
| 1 〜 7 | 名所へ: 1 内湾、2 魚市場、3 第7岸壁、4 浮見堂、5 かなえ大橋、6 大島大橋、7 安波山（ドローンでは飛んで行き、徒歩ではその名所の歩き出し地点に降ります） |
| G | 自動ツアーの開始・停止 |
| V | ドローンと徒歩の切り替え（徒歩では、いまの名所の歩き出し地点に降ります） |
| T | 次の時刻へ |
| K | 次の季節へ（秋 → 冬 → 春 → 夏） |
| O | 小さな惑星のオン・オフ |
| P | 写真（UI なしの 3840×2160 PNG を保存） |
| H | UI を隠す・戻す |
| M | 音のオン・オフ |
| R | 内湾のドローン視点に戻る |
| \` | フレームカウンター（fps、描画コール数、ポリゴン数） |

スマートフォンでは、画面の左側をドラッグすると移動、右側をドラッグすると見回しです。

**画面の配置:**

- **左上:** ライブチップ（時刻、天気、入船 N隻）。クリックすると今日の入船一覧が開きます。
- **右上:** 画質、JA/EN、季節、音、小さな惑星、UI を隠すボタン。スマートフォンでは右端の縦一列（44 px のボタン）になり、名所の帯は端がぼけて横にスクロールできることを示します。
- **左下:** 名所パネル「めぐる」。クリックすると名所の一覧が開き、「自動で巡る」で自動ツアーが始まります。
- **下中央:** 五つの時刻、歩く／空から、写真。

**URL オプション:** `?preset=asa|hiru|yugata|yuyake|yoru`、`?hours=17.1`、`?season=spring|summer|autumn|winter`、`?weather=clear|cloudy|rain|live`、`?wet=0..1`、`?lang=ja|en`、`?q=high|medium|low`、`?fixtures=1`（サンプルデータを強制）、`?places=1`（名所パネルを開いておく）、`?stats`、`?cam=x,y,z>lx,ly,lz`（指定したカメラから始める）。

## 現状と、まだできていないこと

以下は M2 Max での計測値です。マシンを共有していたため、ブラウザは低い優先度（`taskpolicy -b`）で動いていました。通常のブラウザならもっと速いはずです。30 フレームの計測は、回によって最大 ±40 % ぶれました。

- **フレーム時間。** 1920×1080・高画質で 1 フレーム約 11〜19 ms（ドローン 12〜17、遊歩道 11〜14、夜 11〜14、町全体 13〜17、魚市場 17〜19）。1600×900 の実際の画面では 52 fps でした。描画コールは 1 フレームに約 560〜1,060 回で、これが上限になっています。そのため、輪郭線の届かない遠くのまとまり（プリパス）や霧に消えるまとまり（カラーパス）は描画を省いています。魚市場ではまだ 60 fps に届きません。計測値は `dist/qa3/bench_report.json` にあります。
- **中画質。** どの視点でも高画質より速いとは限りません。画素数と影の解像度は減りますが、描画コール数は同じだからです。低画質は 20〜40 % 速くなります。
- **組み立て時間。** ブラウザの中で町を組み立てるのに、速度を絞った状態で約 20 秒かかります。目標は 10 秒です。
- **4K は未実行。** 静止画、30 秒の動画、写真モードのフル解像度 3840×2160 は、1920×1080 以下でしか試していません。共有マシンでは 2026-10-01 00:00Z まで 4K の描画が禁止されていたためです。
- **季節。** 季節で変わるのは、色、雪、花びら、木です。冬は空と海も冷たい色になります。太陽の動きは常にデモ当日の 10月10日 のままです。春は既存の広葉樹の約 3 分の 1 に花を描き足したもので、専用の桜の木のモデルはありません。
- **唐桑。** 唐桑半島は細かい土地被覆の範囲の外にあり、集落もまだないため、名所からは外しています。
- **細部。** 大通りから外れた場所の駐車車両は、単純な箱です。魚市場の岸壁や遠くの岸壁は、内湾ほど小物が多くありません。
- **潮位。** `/api/live` は潮位を返しますが、描画する海面の高さにはまだ反映していません。
