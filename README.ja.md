# 気仙沼 リビングシティ · Kesennuma Living City

[English](README.md)

本物の気仙沼を、手描きアニメ調の町として描いたものです。空から飛び、通りを歩き、道路を車で走り、どの場所でも名前で探せて、魚市場・酒蔵のお店・駅の中にも入れます。今日の天気と今日の入船で、町は動き続けます。

## これは何か

- **計測した、本物の町。** 地形、海岸線、道路、そして 50,826 棟すべての建物の形は、国土地理院のオープンデータから作っています。OpenStreetMap から階数、屋根の形、名前、土地利用、川、信号、道路名を加えています。屋根の色・形・棟の向きは、国土地理院の航空写真から一棟ずつ取っています。どの値にも出典が記録されていて、描いた町は自動の検証で航空写真と比べています（[正確さ](#正確さ) を参照）。
- **手描きのルック。** セル調のエンジンは Kenton-GMI さんの [Sakuragaoka Station](https://github.com/Kenton-GMI/sakuragaoka-station)（MIT ライセンス）を移植したものです。色に合わせた輪郭線、青紫の影、描いた雲、ブルームと色調補正で描きます。
- **中心部のすべてを歩ける。** 地上で歩ける範囲は中心部全体、約 4.3 × 4.4 km です。西は気仙沼駅から内湾まで、北は鹿折から南は南気仙沼と市立病院までです。あなたのまわりを 100 m のタイル単位で読み込みます。遠くは本当の敷地の形に沿った簡略な建物、約 100 m 以内は店先、電柱と電線、自転車、自販機まで描き込んだ建物になります。どこでも歩けて、建物、岸壁の縁、川は壁になります。本物の道路網を軽自動車で走ることも、自由に飛ぶこともできます。
- **本物の名前。** 公共の建物と、OpenStreetMap か国土地理院に名前のあるお店は、看板に本当の名前が出ます。それ以外のお店は、業種に合った架空の名前です。場所検索は約 3,500 の本物の名前を日本語と英語で探せて、近くの場所には名前のラベルが浮かびます。
- **名所は実寸で。** 名所はどれも [docs/anime/landmarks/](docs/anime/landmarks/) の資料シートをもとに、公式・設計・観光の資料から作っています。魚市場（四つの棟すべてと海の市）、かなえ大橋（気仙沼湾横断橋）と気仙沼大島大橋、浮見堂と五十鈴神社のある神明崎、フラップゲートのある魚町の防潮堤、PIER7 と迎（ムカエル）、安波山、市役所、気仙沼駅、リアス・アーク美術館、病院、八つの学校、神社・寺・教会、風待ち地区の登録有形文化財のお店、大島の亀山モノレールと浦の浜のターミナルです。
- **中に入れる建物。** 三つの建物に入れます。魚市場 C棟（見学者入口、2 階の情報発信施設、メカジキが並ぶ水揚げの床を見下ろす見学通路）、魚町の男山本店の店舗、そして改札とその日の発車案内がある気仙沼駅の待合室です。
- **港。** まぐろはえ縄船とさんま船が列になって係留され、岸壁には漁船が並びます。今日入港する船は、実際の船名で魚市場へ入ってきます。PIER7 には湾内遊覧船「ファンタジー」が着き、養殖筏は航空写真に写っている場所にだけ浮かんでいます。
- **移り変わる町。** 時刻は 朝 06:30・昼 12:00・夕方 16:30・夕焼け 17:20・夜 19:30 の五つで、どれも 2026年10月10日 の光で描いています。季節は 春・夏・秋・冬 の四つです。雨と濡れた路面、切り替わる信号、港の環境音もあります。
- **ライブデータ。** 天気は気象庁のアメダスと天気予報、今日の入船は気仙沼漁協の入船情報から取っています。ライブの取得に失敗したときは保存済みのサンプルを表示し、**サンプル** と明記します。サーバーがキャッシュからしか答えられず、それが 1 時間より古いとき（または入船リストが前日以前のもののとき）は、**キャッシュ** とその時刻を表示します。
- **ツアーと写真。** 従来の 7 か所の名所に、44 か所の本物の場所（市役所や駅などの公共の名所 17 か所と、町の場所 27 か所）が加わりました。どの場所にも空からの構図と、近くの道に立つ歩き出し地点があります。自動ツアー、湾全体を見渡す「小さな惑星」表示、3840×2160 の PNG を保存する写真モードもあります。UI は日本語と英語に対応し、スマートフォン用の画面もあります。

## 動かし方

[Bun](https://bun.sh) 1.3 以降と、WebGL2 に対応したデスクトップブラウザが必要です。Apple シリコンの Mac で Chrome か Safari を使うのがおすすめです。

```sh
bun install
bun run build                                  # src/anime を dist/ にまとめる（1 秒未満）
bun run scripts/serve.js --port 8787 --no-build
# http://127.0.0.1:8787/ を開く
```

- `bun run serve` なら、ビルドしてからポート 8787 で配信するまでを一度に行います。
- サーバーは 127.0.0.1 だけで待ち受けます。`/` で `dist/`、`/data/` で `data/` を配信し、`GET /api/live` で今日の天気・潮位・入船を返します。
- 初回の読み込みでは、ブラウザの中で町を組み立てます。進み具合は駅名標に表示されます。共有中で速度を絞った M2 Max では 45〜55 秒かかりました。
- シェルで `NODE_OPTIONS` を設定している場合（デバッガ用など）は、各コマンドの前に `env -u NODE_OPTIONS` を付けてください。

そのほかのコマンド:

```sh
bun test                                       # 29 ファイル・474 件のテスト（レイアウト、データ補強、名所、探索、ライブ、i18n）
bun run scripts/live.js                        # 今日のライブ状態を表示（気象庁 + 気仙沼漁協）
bun run scripts/live.js --fixtures             # 保存済みサンプルの状態
bun tools/anime/check.mjs explore              # ワールドモジュール一つ分のポリゴン数とテクスチャ量の確認（GPU 不要）
bun run scripts/anime/build-explore.js         # data/anime/explore.json を作り直す（決定的、1 秒未満）
```

ブラウザの QA、正確さの検証、スクリーンショット、静止画、動画のツールは、実 GPU を使うヘッドレス Chrome で動きます。詳しくは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#tools) を見てください。

## 操作

駅名標の **まちへ出る · Enter the town** をクリックするか、Enter キーを押します。画面下の案内にもキーの一覧が出ます。

**歩く（「歩く」または V のあと）**

| キー | 操作 |
|---|---|
| W A S D / 矢印キー | 歩く。建物、岸壁の縁、川は壁です。 |
| マウス | 見回す。画面をクリックするとポインタを固定し、Esc で解除します。固定しないときはドラッグで見回します。 |
| Shift | 走る |
| Space | ジャンプ |

**飛ぶ**

| キー | 操作 |
|---|---|
| F | 飛行のオン・オフ（飛行中は壁を通り抜けます） |
| W A S D、マウス | 見ている方向へ秒速 25 m で飛ぶ（Shift で秒速 70 m） |
| E か Space / Q か Ctrl | 上昇 / 下降 |

**運転する**

| キー | 操作 |
|---|---|
| C（または「運転」ボタン） | いちばん近い道路で軽自動車に乗る。もう一度押すと歩道に降ります。 |
| W / S か ↑ / ↓ | アクセル / ブレーキ（止まったあとはバック）。最高速度は時速 40 km（Shift で 60 km）。 |
| A / D か ← / → | ハンドル。手を離すと、いま走っている道の左車線に沿って進みます。 |
| Space | サイドブレーキ |
| マウス | 追いかけるカメラを回す（しばらくすると車の後ろに戻ります） |

車は車道からはみ出さず、縁石に沿って滑り、建物と海で止まり、橋の上も走れます。夕方からはライトがつきます。V、R、F、数字キーを押すと、まず車を降ります。

**場所を探す・移動する**

| キー | 操作 |
|---|---|
| /（または ⌘F / Ctrl+F、「場所を探す」） | 日本語でも英語でも場所を検索します。名前（気仙沼駅、マンボ、"Otokoyama"）でも、種類（病院、寿司、"hospital"、"cafe"）でも探せて、カタカナとひらがなは区別しません（マイヤ = まいや）。↑ ↓ と Enter、またはクリックで選びます。何も入力しないと、名所めぐり、駅・役所・病院・学校、町の名所・お店の一覧が出ます。 |
| N（または「地図」、ミニマップをクリック） | 全体地図。ドラッグで移動、ホイール・ピンチ・＋／−で拡大縮小。場所か道をクリックするとそこへ行きます。 |
| Esc | 検索や地図を閉じる |
| 1 〜 9 | 場所の一覧の最初の九か所へ: 1 内湾、2 魚市場、3 PIER7、4 浮見堂、5 かなえ大橋、6 大島大橋、7 安波山、8 気仙沼市役所、9 ワン・テン庁舎。ドローンでは飛んで行き、徒歩ではその場所の歩き出し地点に立ちます。 |
| G | すべての場所をめぐる自動ツアーの開始・停止 |
| V | ドローンと徒歩の切り替え（徒歩では、いまの名所の歩き出し地点から始まります） |
| R | 内湾のドローン視点に戻る |

検索や地図から場所を選ぶと、歩いているときはその場所の歩き出し地点に立ち、それ以外は空から飛んで行きます。選んだ場所のラベルは、約 300 m 離れるまで表示されたままです。

**時刻・表示・写真**

| キー | 操作 |
|---|---|
| T | 次の時刻へ |
| K | 次の季節へ（秋 → 冬 → 春 → 夏） |
| O | 小さな惑星のオン・オフ |
| P | 写真（UI なしの 3840×2160 PNG を保存） |
| H | UI を隠す・戻す |
| M | 音のオン・オフ |
| \` | フレームカウンター（fps、描画コール数、ポリゴン数） |

スマートフォンでは、画面の左側をドラッグすると移動（運転中は運転）、右側をドラッグすると見回しです。

**建物の中へ。** キーは要りません。入口から歩いて入ります。

- **魚市場 C棟:** 魚市場 を検索するか 2 を押します。陸側の壁にあるガラスの見学者入口から入り、階段で 2 階の見学通路へ上がります。
- **男山本店:** 男山 を検索します。魚町の海沿いの道に面していて、店の入口は通りを向いています。
- **気仙沼駅:** 気仙沼駅 を検索し、アーケードを抜けて待合室へ入ります。

**画面の配置**

- **左上:** ライブチップ（時刻、天気、入船 N隻）。クリックすると今日の入船一覧が開きます。
- **右上:** 画質、JA/EN、季節、音、小さな惑星、UI を隠すボタン。その下に「場所を探す」「地図」「運転」があります。
- **右下:** ミニマップ（北が上）。あなたの位置、向き、視野と、いる町名と道路名を表示します。運転中は下中央に速度と道路名が出ます。
- **左下:** 名所パネル「めぐる」。クリックするとすべての場所の一覧が開き、「自動で巡る」で自動ツアーが始まります。
- **下中央:** 五つの時刻、歩く／空から、写真。
- **下端:** 出典表記「© OpenStreetMap contributors · 出典：国土地理院, 気象庁, 気仙沼漁協 · Sakuragaoka Station (MIT) by Kenton-GMI」とライセンスへのリンク。全体地図にも地図データの出典を表示します。

スマートフォンでは、ボタンは右端の縦一列（44 px）になり、ミニマップは左上に移り、ラベルは一度に 10 個までです。

**URL オプション:** `?preset=asa|hiru|yugata|yuyake|yoru`、`?hours=17.1`、`?season=spring|summer|autumn|winter`、`?weather=clear|cloudy|rain|live`、`?wet=0..1`、`?lang=ja|en`、`?q=high|medium|low`、`?fixtures=1`（サンプルデータを強制）、`?places=1`（名所パネルを開いておく）、`?stats`、`?cam=x,y,z>lx,ly,lz`（指定したカメラから始める）、`?stream=0`（地上の読み込みを止め、v3 と同じく中間ゾーンを町モジュールが作る）、`?labels=0`（船のラベルを隠す）、`?credit=1`（静止画に出典を入れる）。

## 正確さ

作り込みより正確さを優先しています。気仙沼に住む人が、自分の通りだとわかることが目標です。方法は四つです。

1. **本物の資料を先に、値ごとに出典を。** 敷地ごとに、どの値をどこから取ったかを `lot.src` に記録しています。優先順位は OpenStreetMap、航空写真、国土地理院の施設注記、最後にまわりから推定した値です。出典の一覧は `data/anime/sources.json` と [docs/DATA-SOURCES.md](docs/DATA-SOURCES.md) にあります。
2. **名所ごとの資料シート。** 名所ごとに `docs/anime/landmarks/` のシートがあり、寸法・色・位置とその出典を書いています。作る側は寸法を一つの表（`src/anime/world/harbor/real.js`、`src/anime/world/landmarks/sites.js`）から読みます。ウェブの写真は形と色の参考にだけ使い、アプリには入れていません。
3. **自動の検証。** `tools/anime/accuracy.mjs` が、動いているアプリを真上から正射投影で描き（中心部、内湾を囲む半径 1.1 km の円、500 m × 24 枚、0.5 m/px）、国土地理院の建物の形、z18 の航空写真、OpenStreetMap の道路、名所のシートと比べます。タイルごとに写真・描画・差分を並べた画像も保存します。
4. **地上での確認。** `tools/anime/qa3.mjs` がすべての場所を歩きます。歩き出し地点は陸の上で、どの建物の外にもあり、その場所が見えていなければなりません。読み込み、歩行、運転、検索、地図、建物の中、ラベルも確かめます（146 項目）。

最新の検証（中心部、2026-09-30 20:18Z、`accuracy.mjs --tag docs4` が書いた `dist/qa4/accuracy_docs4.json`）:

| 指標 | 目標 | 結果 |
|---|---|---|
| 建物の占める範囲の IoU（国土地理院の建物の形と比較） | 0.80 以上 | **0.870**（再現率 0.940、適合率 0.921） |
| 名所の位置の誤差 | 5 m 未満 | **15 か所すべて** 5 m 未満（最大 3.7 m、かなえ大橋の主塔） |
| 屋根の色の CIEDE2000（航空写真と比較）の中央値 | 小さいほどよい | 7.16（写真全体の色かぶりを除くと 5.63）。10 未満の屋根が 67 % |
| 建物の高さの絶対誤差の中央値（OSM と資料シート、75 棟） | 小さいほどよい | 1.1 m |
| OSM の道路中心線のうち、描いた道路が覆う割合 | 大きいほどよい | 0.905 |
| 描いたアスファルトと OSM の車道（幅つき）の重なり | 大きいほどよい | 適合率 0.576、再現率 0.786 |

数字の読み方について二つ。建物は IoU の比較相手と同じ国土地理院の形の上に建てているので、IoU は「その形にどれだけ忠実に建てたか」（軒下に下がった壁、棟の組み合わせ、名所への置き換え）を表し、国土地理院の形そのものの正しさではありません。屋根の色、高さ、名所、道路は、それとは別の資料と比べています。道路の適合率が低いのには理由があります。描いたアスファルトの面積は OSM の車道の約 1.36 倍（約 369,000 m² 対 271,000 m²）です。OSM の道に `width` か `lanes` のタグがあればアスファルトはそれに従い、残りの幅は歩道になります。内湾の外の多くの道にはどちらのタグもないため、アスファルトは国土地理院で測った道路の幅いっぱいに広がり、検証側は OSM の道路種別の標準幅を使います。

## 現状と、まだできていないこと

以下は M2 Max での計測値です。マシンを共有していたため、ブラウザは低い優先度（`taskpolicy -b`、`nice 15`）で動いていました。静かなマシンで通常のブラウザを使えば、ずっと速いはずです。

- **フレームレート。** 制限をかけた状態で、1920×1080・高画質の 1 フレームは 20〜32 ms でした（遊歩道 19.7、魚市場 23.9、ドローン 25.3、夜 30.3、町全体 32.0。`dist/qa3/bench_report.json`、2026-09-30）。低画質は 19〜22 ms です。1600×900・高画質の実際の画面では、2 回の計測で、内湾でも遠くの中心部を読み込みながらでも 13〜16 fps でした。1 フレームの描画コールは約 950〜1,550 回、ポリゴンは 1,200 万〜1,400 万で、描画コール数が上限になっています。v3 は同じ Mac が空いていたときに 52 fps でしたので、高画質 60 fps の目標は静かなマシンであらためて計測する必要があります。
- **読み込み時間。** 制限下で、ページの準備ができるまで 45〜55 秒かかりました。そのうち町の組み立てが 20〜27 秒、町モジュールだけで 10〜15 秒（主に日本語の文字をテクスチャに描く時間）です。目標は 10 秒です。
- **4K。** 静止画、30 秒の動画、写真モードのフル解像度 3840×2160 は、1920×1080 以下でしか試していません。
- **建物の中。** 入れるのは三つの建物だけです。ほかの建物は中に入れませんが、内湾のお店はガラス越しに部屋が見えます。
- **町の細部。** 内湾の外の駐車車両は単純な箱で、100 m より遠い建物は簡略な形です。唐桑と市の外側には地形・建物の形・道路はありますが、地上の読み込みはありません。
- **季節。** 太陽の動きは常にデモ当日の 10月10日 のままです。春は広葉樹に花を描き足したもので、専用の桜の木のモデルはありません。
- **潮位。** `/api/live` は潮位を返しますが、描画する海面の高さにはまだ反映していません。
- **運転。** 車は一台だけで、ほかの交通はありません。信号は切り替わりますが、道路の上でそれに従うものはまだありません。
